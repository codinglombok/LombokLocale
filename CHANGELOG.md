# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.2.0] — 2026-10-02

### Added
- Python, Go and PHP ports; all five ports run the same 342 shared vectors.
- CLDR 47.0.0 data for 28 locales (numbers, currencies, dates) and plural rules for all CLDR locales, generated from `cldr-json` by `scripts/extract_cldr.py` and `scripts/gen_ports.py`.
- Percent style, minimum fraction digits, Indian grouping and minimum grouping digits.
- Date styles full/long/medium/short with CLDR month and day names.
- MessageFormat: `offset`, `=n` keys, `{n, number[, integer|percent]}`, `{d, date[, style]}`, apostrophe quoting, `#` formatted for the locale.
- BCP 47 extensions, private use and variant rules; error codes shared by every port.
- `vectors/check_icu.mjs` cross-checks number, date and plural vectors against ICU.
- `LICENSE-UNICODE` for the embedded CLDR data.

### Changed
- Plural rules are evaluated from CLDR data instead of a hand-written list.
- Number, currency and date output follow CLDR patterns and symbols.
- Negotiation is a plain RFC 4647 lookup.
- Catalog parsing rejects duplicate keys, lone surrogates and deep nesting.
- Rust MSRV is 1.70; the crate stays `no_std` + `alloc`.

### Fixed
- `pl` 21 was "one" (CLDR: "many"); `hr`/`sr`/`bs` used "many" (CLDR: "other"); millions in `fr`/`es`/`pt` now use "many".
- Currency symbols were placed before the amount for `de`, `es` and others; JPY, KRW and VND used two decimals.
- Dates were formatted correctly only for `en` and `id`.
- Vector expectations were generated by the Rust port itself; they now come from an independent model and are checked against ICU.

### Removed
- `scripts/lombok-doctor-docs.sh` (replaced by `scripts/lombok-doctor.sh`) and `vectors/gen_inputs.py`.

## [0.1.0] — 2026-09-30

Initial version: Rust reference and TypeScript port (not published to any registry).
